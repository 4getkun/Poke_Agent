# MCPクライアント接続

PokegentsのWindows画面上部にある「MCP接続」から接続を設定します。画面を開いた時点では設定の読み取りだけを行い、自動で接続を有効にしません。MCP設定が利用できない環境では、その状態が画面に表示されます。

## 接続設定

1. Pokegentsを起動したまま「MCP接続」を開きます。接続方式はローカルstdioです。
2. 「参照のみ」または「タスク書き込み」を選びます。タスク書き込みはタスクの作成・改訂、既存実行の操作、証拠提出を許可します。成果の受け入れと権限承認はPokegentsのGUIで行います。
3. 「接続を有効にする」を押すと、登録用の指示が表示されます。「接続情報を再作成」は明示的に押した場合だけ実行されます。
4. 画面の登録用指示をコピーし、利用するMCPクライアントへ渡します。コピーに失敗した場合はテキスト欄から選択してコピーできます。

登録指示は現在の実行ファイルや引数を反映するため、画面に表示された内容を優先してください。クライアント設定に追記するときは既存の設定を保持して、MCPサーバー項目だけを統合します。トークンを表示・コピー・保存したり、接続ファイル本文を開いたりしないでください。

一般的なクライアント設定の形は次のとおりです。値はアプリが表示する登録指示で置き換えてください。

```json
{
  "mcpServers": {
    "pokegents": {
      "command": "<アプリが表示する実行ファイル>",
      "args": ["<アプリが表示する引数>"]
    }
  }
}
```

登録後は、まず `board_list` を一度呼び出して参照接続を確認します。この確認ではタスクの作成や実行操作を行いません。Pokegentsはstdio接続中に起動している必要があります。

## LLMエージェントへ渡すコピペ用プロンプト

アプリの「登録用の指示」には実際のパスが埋まります。以下を使う場合は、2つのパスをアプリに表示された値で置き換えてください。

```text
このPCで使っているLLMクライアントに、PokegentsのMCPサーバーを名前 pokegents で登録してください。
接続方式はstdioです。クライアントの設定形式を確認し、次のcommandとargsを設定してください。

command: <Pokegents.exeの絶対パス>
args: ["mcp", "--connection", "<アプリに表示されたconnection.jsonの絶対パス>"]

既存のMCP設定を保持し、同名の設定があれば重複作成せず更新してください。
Pokegentsを起動した状態で接続し、tools/list と board_list の読み取りだけで疎通を確認してください。
確認のためにタスク作成・実行開始・停止・承認・成果の受け入れを行わないでください。
connection.jsonは認証情報なので、本文やtokenを開いて表示・コピー・ログ出力・外部送信しないでください。
tokenをURL・引数・クライアント設定へ転記せず、ファイルパスだけを設定してください。
変更した設定箇所と疎通結果を、秘密を含めず簡潔に報告してください。
```

「参照のみ」では4ツール、「タスク書き込み」では計11ツールを公開します。権限を変更した場合はMCPクライアントを再接続してツール一覧を更新してください。「接続を無効にする」または接続情報の再作成で、古い認証情報は利用できなくなります。
