# ローカルMCP連携

2026-10-20のユーザー追加依頼により、仕様書2.2で後続扱いだったMCP公開を前倒しする。既存のG1〜G4や状態・権限制約は免除しない。

Agent_BoardのstdioアダプターからローカルHTTPアプリへ接続する構成を参考に、Go公式MCP SDK v1.8.0を使う。`Pokegents.exe mcp --connection <絶対パス>` はstdioのみを扱い、DB・ランタイム・別HTTP listenerを生成しない。アプリの既存Serviceへ接続する。

MCPは既定で無効。GUIから参照のみ／タスク操作を選んで有効化する。UIの認証トークンと異なる専用32バイト乱数をowner-only ACLの接続ファイルへ保存し、SQLiteには有効状態・scope・tokenのSHA-256を保持する。APIはloopback限定、Host/Originを確認し、MCP専用ルートのみ専用資格情報を受け付ける。無効化・再作成・scope変更で旧資格情報を失効させる。登録プロンプトは実行ファイルと接続ファイルのパスだけを含む。

参照4ツールと、タスク操作を含む計11ツールを公開する。実行は既存のCodex/Job/受け入れゲートを通る。成果受け入れ・承認応答・復旧確認・任意コマンド・架空の外部run所有権は公開しない。Agent_Boardのclaim/releaseを、実プロセス管理の根拠なしにコピーしない。

登録先のクライアント設定は自動変更しない。利用者がGUIのプロンプトを渡して登録し、board_listによる読み取り確認を行う。クライアント側の既存設定と認証情報を保つ。実クライアントの個別設定変更と、テスト用MCP clientによるnative stdio試験は別の証拠として扱う。
